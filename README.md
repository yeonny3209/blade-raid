# BLADE RAID (블레이드 레이드)

브라우저와 안드로이드에서 즐기는 2D 액션 RPG. 검 하나로 던전을 돌파하고, 보스를 쓰러뜨리고, 무한의 탑을 올라간다.

- 바로 플레이: https://yeonny3209.github.io/blade-raid/
- 안드로이드 앱(APK): [Releases](https://github.com/yeonny3209/blade-raid/releases/latest)
- 진행 중인 이벤트: [탑을 오르는 자들](https://yeonny3209.github.io/blade-raid/event.html)

## 특징
- **던전 20개 + 무한의 탑 (200층까지 + 그 위로 끝없는 수호자)** — 던전마다 테마·보스가 다르고, 보스 20종은 몸과 패턴이 전부 다르다.
- **검 24종 · 방어구 16종** — 검마다 타격감, 패시브, 고유 스킬 2개(G · R)가 다르다.
- **장비 강화 (+15) · 난이도 4단계** (쉬움 / 보통 / 어려움 / 지옥)
- **도감 · 업적** — 몬스터와 보스를 처음 처치하면 보상.
- **기록 카드** — 결과 화면에서 이미지로 저장해 공유.
- **모바일 지원** — 가로 화면 터치 조작, 홈 화면에 설치(PWA), 오프라인 플레이.

## 조작 (PC)
| 키 | 동작 |
|---|---|
| W A S D / 방향키 | 이동 (같은 방향 두 번 = 대시) |
| 좌클릭 / J | 기본 공격 |
| Space | 점프 |
| Z / L | 백스텝 (무적) |
| Q E T F | 장비 공통 스킬 |
| G R | 장비 고유 스킬 |
| C V (1 2) | HP / MP 물약 |
| Esc | 일시정지 (계속하기 · 설정 · 로비로 나가기) |
| B / N / K / O / H | 상점 / 무한의 탑 / 도감 / 설정 / 난이도 (로비) |

## 개발
순수 JavaScript + Canvas 2D (프레임워크·빌드 도구 없음). 로컬 실행:

```bash
python -m http.server 8765
```

안드로이드 APK 빌드는 `android/build.sh` (JDK + Android SDK 필요, Gradle 불필요).
